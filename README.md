# 📈 StockBot — телеграм-бот: изменения цен акций Мосбиржи

Слепит за акциями MOEX (источник — официальный бесплатный ISS API, ключ не нужен)
и присылает в Telegram:

- **алерты по порогу** — когда цена уходит более чем на N% от предыдущего закрытия
  (пауза между повторными алертами настраивается);
- **периодические сводки** — все акции из списка с текущей ценой и изменением.

Работает через long polling — публичный IP, вебхуки и домен **не нужны**.
Можно запустить на любом сервере (VPS) или на постоянно включённом компьютере.

## Команды бота

| Команда | Описание |
|---|---|
| `/watch SBER GAZP` | добавить акции в список (можно просто написать тикер сообщением) |
| `/unwatch SBER` | убрать из списка |
| `/list` | список с текущими ценами |
| `/alert 5` | порог алерта, % изменения за день (0.1–50, по умолчанию 5) |
| `/quiet 30` | мин. пауза между повторными алертами, мин (по умолчанию 30) |
| `/report 60` | сводка каждые N минут, `0` — выключить (по умолчанию 60) |
| `/help` | помощь и текущие настройки |

Настройки хранятся отдельно для каждого пользователя — ботом может пользоваться
несколько человек одновременно.

## Быстрый старт

```bash
cd stockbot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# токен бота (у @BotFather, /token)
cp .env.example .env   # и вписать BOT_TOKEN
# либо: export BOT_TOKEN='123456:ABC...'

.venv/bin/python bot.py
```

После запуска напиши боту `/start`, потом `/watch SBER GAZP`.
Первая сводка придёт сразу, дальше — раз в час (или с интервалом из `/report`),
алерты — при превышении порога, пока рынок торгует.

## Деплой

### Вариант 1: Docker (рекомендую для VPS)

```bash
docker build -t stockbot .
docker run -d --name stockbot --restart unless-stopped \
  -e BOT_TOKEN='123456:ABC...' \
  -v stockbot_data:/app/data \
  stockbot
```

### Вариант 2: systemd

```bash
sudo useradd -r -m -d /opt/stockbot stockbot
sudo git clone <repo> /opt/stockbot   # или скопировать файлы
cd /opt/stockbot
sudo -u stockbot python3 -m venv .venv
sudo -u stockbot .venv/bin/pip install -r requirements.txt
# вписать BOT_TOKEN в /opt/stockbot/.env
sudo cp stockbot.service /etc/systemd/system/
sudo systemctl enable --now stockbot
journalctl -u stockbot -f   # логи
```

## Как это устроено

- Цены: `candles.json` (минутные свечи) ISS API. Последний тикер в окне
  от последней увиденной свечи — это «текущая цена» (точность до минуты).
- Предыдущее закрытие, название, валюта, число знаков — таблица ценных бумаг
  (`…/boards/TQBR/securities/{TICKER}.json`), кэшируется на час.
- «Рынок открыт» определяется по свежести последней свечи (< 10 мин).
- Алерты отправляются только при свежих данных, чтобы после закрытия торгов
  не зациклиться на неизменной цене; между повторами — пауза `/quiet`.
- Опрос всех пользователей и тикеров — каждые `CHECK_INTERVAL_SEC` (60 c),
  каждый тикер опрашивается один раз за тик, сколько бы пользователей им
    не интересовались.
- Настройки пользователей: `data/users.json` (переживает перезапуск).

## Ограничения

- Точность цены — до 1 минуты (так отдаёт ISS API).
- Во время закрытия рынка цены статичны — это нормально.
- Тикеры ищутся на торговых режимах TQBR (основной, T+), затем TQDR, SPEQ.


## Стакан, лента сделок и сигналы о роботах (T-Invest API)

Бесплатный ISS Мосбиржи не отдаёт стакан, а лента идёт с задержкой 15 мин.
Поэтому эти функции работают через **T-Invest API** (Т-Банк Инвестиции):

1. В приложении Т-Банка: Инвестиции → Настройки → **Токены для API** →
   создать токен **«Только для чтения»** (боту торговать не нужно).
2. Добавить переменную окружения `TINKOFF_TOKEN=<токен>` (в панели хостинга
   или в `.env`). В репозиторий токен не кладём.
3. Перезапустить бота. В логе появится
   `flow: анализ ленты и стакана запущен`.

Без токена команды `/book`, `/tape`, `/flow` и кнопки «Стакан/Лента»
просто сообщают, что функция выключена — остальное работает как раньше.

Папка `certs/` содержит корневые сертификаты Минцифры РФ: ими подписан
`invest-public-api.tinkoff.ru`, и вне России без них TLS не проходит.

### Сигналы (эвристики, а не гарантия)
| | Сигнал | Что смотрим |
|---|---|---|
| 🧊 | Айсберг | ≥8 сделок одного объёма по одной цене за 3 мин |
| 🤖 | Ритм | ≥10 сделок одной стороны с почти равным интервалом (TWAP/VWAP) |
| ⚖️ | Перекос | ≥80% объёма за 5 мин в одну сторону при движении цены ≤0,15% |
| 🔥 | Всплеск | сделок за минуту ≥4× медианы предыдущих минут |
| 🧱 | Плотность | уровень стакана ≥8× медианы остальных уровней |
| 👻 | Спуфинг | крупная заявка исчезла ≤90 c, цена до неё не дошла |

Пороги — константы в начале `tape.py`. Один и тот же сигнал по бумаге
повторяется не чаще раза в 15 мин; выключить: `/flow off`.


## Умные сигналы: контекст, проверка результата, статистика

- Под каждым сигналом — блок 📍 **контекст**: изменение к закрытию, положение
  в диапазоне дня (H/L), VWAP, перевес стакана.
- Через 5 и 15 минут бот **дописывает к сообщению результат**
  («⏱ После сигнала → 5м: +0,12% ➖ · 15м: +0,45% ✅»). ✅/❌ — цена пошла
  в сторону сигнала / против на ≥0,2%.
- `/stats [дней] [TICKER]` — таблица: сколько сигналов каждого типа по бумаге,
  среднее движение через 15 мин и доля «попаданий». Журнал — `data/signals.json`.
- `/backtest TICKER` — прогнать детекторы по ленте за последний час прямо сейчас.
- Пороги адаптивные: бот копит «норму» частоты и размера сделок по каждой
  бумаге (Baseline) и масштабирует пороги айсберга/всплеска под неё.
- Новые сигналы: 🐋 **кит** (одна сделка ≥ 20 млн ₽ и ≥ 25× типичной),
  🍽 **стену съели** (плотность простояла и исполнена — пробой уровня).
- Сигналы по бумаге группируются в один дайджест (первый — сразу, дальше —
  раз в 2 мин, до 4 в сообщении). Детекторы работают всё торговое время:
  06:50–23:50 МСК, включая утреннюю и вечернюю сессии.
- `/quiethours 23 9` — тихие часы (МСК) для всех уведомлений; `off` — выключить.
- На графике (1м–4ч): линии H/L дня, VWAP, зоны плотностей из стакана;
  на 1м/5м/15м — кумулятивная дельта (покупки − продажи) поверх объёма.


## Новости → отдельный канал

Бот опрашивает каждые 30 с: Интерфакс, РБК, ТАСС, Коммерсантъ, Финам,
Смарт-Лаб, ленту новостей MOEX (приостановки/дискретные аукционы). Новость
матчится с бумагами из watchlist (тикер + название + синонимы: «Сбер/Греф»)
и с рыночными триггерами (ЦБ/ставка, санкции против РФ, нефть, рубль, налоги…).
Приоритет: ⚡️ (дивиденды, buyback, ЧП, ставка, MOEX) · ❗️ · ℹ️.

Настройка:
1. Создай канал, добавь бота **администратором** с правом публикации.
2. Напиши в канале любое сообщение — в логе бота появится `канал: id=-100…`.
3. Переменные: `NEWS_CHANNEL=-100…` (или `@username`), опц. `NEWS_MODE`:
   `stocks` (по умолчанию — все бумаги РФ из словаря ~130 эмитентов + рынок),
   `watch` (только мои), `market` (мои + рынок), `all` (всё подряд).
4. Перезапуск. `/news` в личке — статус источников и последние релевантные.

Под новостью — кнопки тикера: график / стакан / лента / Т-Инвестиции /
Терминал. Нажатия в канале обрабатываются ботом, ответ приходит **в личку**.


## Источник котировок и задержка

Бесплатный ISS Мосбиржи отдаёт цены и свечи **с задержкой 15 минут**.
Если задан `TINKOFF_TOKEN`, бот берёт из T-Invest API в реальном времени:
свечи для графиков (все таймфреймы нативно), последние цены для алертов,
сводок и `/list`. MOEX остаётся резервом (справочник бумаг, пред. закрытие,
и все данные, если T-Invest недоступен). Источник подписан в углу графика.


## Кластерный анализ — `/clusters SBER [5m|15m|30m|1h|4h|1d]`

Объём по ценовым уровням и по времени с разделением на агрессивные покупки
и продажи (по направлению сделок из ленты T-Invest): дельта, % покупок,
POC, зона 70% объёма, тепловая карта «время × цена», профиль объёма,
накопленная дельта. Подсвечивает расхождения (покупают — цена падает и т.п.).
T-Invest отдаёт ленту только за час, поэтому бот копит её сам по бумагам
из списков (`data/clusters.json`, 5 дней). Кнопка 🧮 есть под графиком,
стаканом, лентой и сигналами.


## Сетап — `/setup SBER`

Сводка «за / против» перед входом: уровни по объёму (POC каждого дня + узлы
объёма за 5 дней) и их тесты (удержан/пробит, объём и дельта на касании),
дельта 15м/1ч и расхождение с ценой, VWAP и диапазон дня, перекос и плотности
стакана, свежие сигналы, относительная сила к IMOEX (15 мин и день),
аномальный объём к норме этого времени суток, фаза сессии. Итог —
взвешенный счёт за лонг/шорт. Кнопка 🎯 есть под графиком, кластерами,
стаканом, лентой и сигналами. Уровни по объёму рисуются на графиках.

Новые автоматические сигналы: 📏 подход к уровню по объёму (с историей
тестов) и 📊 аномальный объём (≥4× нормы этого времени дня, нужна история
≥3 дней). `/stats` дополнительно показывает, в каких условиях сигналы
работали (по VWAP, дельте, силе к рынку, времени дня) — когда наберётся
≥8 сигналов с результатом.


## Киты — адаптивные пороги

🐋 одиночный кит: сделка ≥ p99,9 размеров сделок этой бумаги (по её же ленте
T-Invest, копится с запуска, нужно ≥2000 сделок) и не меньше рублёвого пола
(`tape.WHALE_FLOOR_RUB`: SBER 50 млн, GAZP/YDEX/PLZL 5 млн, RUAL 3 млн,
прочие 5 млн ₽). 🐋🐋 серия китов: ≥3 сделок одной стороны от p99 (не мельче
1/10 пола) за 2 мин — с выводом «поглощает / продавливает». Под китами
контекстный блок (VWAP/стакан/IMOEX) не показывается.


### Новости: рыночные события

Источники дополнены RSS Банка России (пресс-релизы и заявления — решение по
ставке приходит в 13:30 напрямую, раньше СМИ). Рыночные события уровня ⚡️/❗️
(решение по ставке, анонс заседания, недельная инфляция, санкции против РФ,
приостановка торгов, геополитика, налоги) публикуются в любом режиме, кроме
`watch`. Одинаковые сюжеты от разных агентств в течение 30 мин схлопываются.


### Источники новостей (итог)

Агентства/СМИ (опрос раз в `NEWS_INTERVAL_SEC`=30 с): Интерфакс, РБК, ТАСС,
Коммерсантъ, Ведомости, ПРАЙМ, Финам, Смарт-Лаб. Первоисточники (быстрый
контур, `NEWS_FAST_INTERVAL_SEC`=8 с): Банк России (2 ленты), MOEX ISS,
Правительство РФ, Минфин (гео-блок вне РФ), Росстат (российский сертификат;
RSS может отсутствовать). e-disclosure закрыт капчей. Недоступные источники
пишутся в лог раз в 30 мин («источник X недоступен»).

Фильтры: PR-шум по тикеру (мошенники, сервисы, опросы, подстанции…) не
постится; «на Мосбирже» не считается тикером MOEX; в дайджестах тикеры
ищутся только в заголовке; движение индекса/рынка ≥1% — ❗️ «рынок».


## Кнопка «⚡ CScalp» — открыть бумагу в CScalp на вашем ПК

Telegram не умеет открывать десктопные приложения, а у CScalp нет API, поэтому
работает «мостик»: скрипт `cscalp_bridge.py` на Windows (обычный ПК или
Windows в Parallels) раз в секунду спрашивает бота, нет ли команды, и,
получив тикер, кликает по заголовку стакана CScalp, вставляет тикер в поиск и
жмёт Enter. Ваш ПК не должен быть доступен снаружи — мостик сам ходит к боту.

**На стороне бота (Bothost → переменные окружения):**
- `CSCALP_KEY` — длинная случайная строка (например `openssl rand -hex 16`);
- `OWNER_ID` — ваш Telegram id (кнопка и команда только для вас);
- порт: бот слушает `PORT` (Bothost задаёт сам). Нужен публичный URL
  приложения (в панели Bothost — раздел Webhooks/Domains; вида
  `https://<app>.bothost.ru`). Проверка: открыть `<url>/` — ответ `ok`.

**На Windows (один раз):**
```
pip install requests pywinauto pyautogui pyperclip
python cscalp_bridge.py            # создаст cscalp_bridge.ini
```
В `cscalp_bridge.ini` вписать `url` и `key`. Затем:
```
python cscalp_bridge.py --calibrate   # навести мышь на заголовок стакана (тикер), Enter
python cscalp_bridge.py --test SBER   # должен переключить стакан
python cscalp_bridge.py               # рабочий режим (оставить запущенным)
```
Автозапуск: ярлык на `pythonw.exe C:\путь\cscalp_bridge.py` в папке
`shell:startup`. Лог — `cscalp_bridge.log` рядом.

Сначала мостик пробует найти заголовок стакана через UI Automation (не
зависит от положения окна); если CScalp не отдаёт элементы — кликает по
откалиброванной точке, поэтому окно стакана лучше не двигать. Если CScalp
свёрнут — мостик его развернёт. Статус: `/cscalp` без аргументов.


## Меню

При старте бот сам регистрирует список команд (`set_my_commands`) — они
видны в синей кнопке «Меню» слева от поля ввода, BotFather не нужен. После
`/start` и `/help` появляется постоянная клавиатура частых действий (Список,
Сетап, Кластеры, График, Стакан, Лента, Статистика, Новости, Настройки); для
команд с тикером при нескольких бумагах в списке бот предложит выбрать.


## Очистка чата — `/clear`, `/autoclear`

Бот учитывает все свои сообщения в личках (`data/sent.json`) и по умолчанию
удаляет их **ежедневно в 03:00 МСК** (`/autoclear 5` — другой час,
`/autoclear off` — выключить). `/clear` — удалить сейчас, `/clear 6` — только
старше 6 часов. Ограничения Telegram: удаляются только сообщения бота и не
старше 48 часов; команды пользователя остаются. Новостной канал не трогается.
Новый файл: `cleaner.py`.
